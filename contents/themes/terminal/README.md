# Terminal (green-phosphor ASCII sea)

Plan (step 1; the finished design note replaces this file in the last step).

- Look: a green-phosphor terminal. Every creature is a block of text characters, drawn from a real
  pixel font (Terminus 6x12, `ter-u12n.otb`, PIL bitmap). One font pixel is one texel; the screen
  texel is `round(height / 540)` device px (2 px at 1080p), so a text cell is 12x24 px at 1080p and
  the whole sea is a 160 x 45 character grid. Scaling is integer and nearest-neighbour: crisp.
- Palette: near-black green background, three phosphor greens (bright, normal, dim). Stress recolours
  fish amber then red; a hot fish alternates red and an inverted red at most ~1 Hz. Night uses the
  dimmer variant of every set. No gradients, no shades (░▒▓ are dither patterns and are not used).
- Sprites: generated by tools/gen-terminal-theme.py from the glyph runs in theme.js; one PNG per
  creature, frame, facing and palette set. Left-facing art is the right-facing art with mirrored
  characters and reversed columns, selected by file (never mirrored in QML).
- Motion: the simulation at 25 Hz, glide between ticks as in onebit (whole screen pixels).
- Backdrop: static waves line, a sparse dim dot lattice, a seabed of ground characters, kelp that sways
  2 frames at 0.5 Hz, a static prompt line with a non-blinking cursor and an htop-style load bar that
  changes only when its 5 % step changes.
